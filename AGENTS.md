# Instrucciones de colaboración

- Producto de Martín para desarrollar con Fabián. Nombre y modelo comercial pendientes.
- Usar solo datos ficticios en pruebas. No agregar credenciales, cookies, tokens ni datos reales de clientes o documentos.
- Conservar reglas en model.js, interfaz en app.js y ui.html, persistencia en backend.gs.
- Conservar documento y matrícula como texto y la copia de transporte en cada retiro.
- Antes de entregar cambios funcionales ejecutar node qa/checks.js y reconstruir con python3 build.py.
- Distinguir validación local, backend simulado y prueba real de Sheets.
- La memoria personal y los sistemas de Estawol quedan fuera del repositorio de producto.
- Mantener documentación y PDF alineados con la versión realmente implementada. No prometer funciones o validación comercial pendientes.
